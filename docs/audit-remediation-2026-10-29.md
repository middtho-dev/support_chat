# Исправления после аудита Workspace · 2026-10-29

Область: поддержка, FRP, Voice, Editor, Video, Lampac/TorrServer и Firmware.
Новые пользовательские сценарии не добавлялись; восстановлены согласованные
статусы, настройки, доставка и эксплуатационные проверки.

| Обнаружено | Изменение |
|---|---|
| Нет актуальной общей копии | Ежедневный проверенный снимок 16 компонентов, SHA-256, online SQLite backup, семь снимков, проверка восстановления |
| Уязвимости npm | Обновлены Express, Multer, Socket.IO, better-sqlite3, qs, транзитивные зависимости и Undici; npm audit: 0 для обоих lockfiles |
| Node 20 после EOL | Поддержка, FRP, Voice и Video переведены на Node 24 LTS; исправлен запуск тестов под Node 24 |
| Сбой уведомления оставляет закрытие незавершённым | Сохраняемая финализация, повторные попытки, восстановление после перезапуска |
| Старая кнопка закрывает новое обращение | Проверка ID обращения и актуальной управляющей карточки, совместимость старых кнопок только на актуальной карточке |
| Сохранённый ответ теряется при закрытии | Очередь завершает ручные ответы перед финальным уведомлением, новое обращение прекращает старую финализацию |
| История пропускает сообщения одной секунды | Составной курсор времени и последовательности, проверка принадлежности курсора обращению |
| Неверное отображение прав владельца | Серверные владельцы отмечены и защищены в интерфейсе и API; обычные операторы редактируются |
| Отменённый веб-таймер всё ещё активен на экране | Карточка меняется после продолжения, закрытия и перезагрузки; кнопка убирается |
| Настройки не действуют в Rich dialog | Скрыты настройки тем, draft-эффекта и неподдерживаемых отступов; текст/стиль кнопки применяются |
| Выключенный модуль считается сломанным | Отдельное нейтральное состояние; общая копия контролируется по реальной свежести |
| Неполная CI-проверка | Добавлены Python-тесты, резервирование, Chromium/WebKit, телефон/ПК и клиентские сценарии |
| Неограниченные логи/ресурсы, Firmware от root | Ротация и ограничения сервисов, Firmware от непривилегированного пользователя и readiness healthcheck |
| Противоречивые правила | Общая дизайн-система, актуальные Node/режимы Telegram и инструкция восстановления |

Проверки интерфейса выполняются только на синтетических данных без Telegram
ключей. Снимки подтверждений, телефона, ПК и мини-проектов просматриваются
отдельно от автоматической проверки геометрии. Изменения не сбрасывают сессии.

Ограничения: внешнее хранилище копий не выбрано; локальные копии не защищают от
потери VPS. Реальные Telegram-клиенты, физический iPhone/Android/TV и прошивка
физического роутера не проверялись. API Telegram может запрещать удаление старых
сообщений — заблокированные удаления остаются видны, успешная очистка не
имитируется. Доступ к вложению по случайному известному URL сохранён для
совместимости доставки медиа; изменение модели доступа требует отдельного
согласования. Billing lock GitHub Actions не является успешным результатом CI.
