# Редактор Telegram Business

Отдельный модуль исходящих **текстовых** сообщений. Workspace → Редактор.
У модуля свои настройки, список владельцев аккаунтов, очередь, дневной лимит
и журнал. Обработка аудио и её настройки не меняются.

Использует существующее Business-подключение, OpenAI API key и VPN сервиса
`tools/voice`. Один бот получает обновления один раз, затем распределяет их
по независимым обработчикам. Редактор может работать при выключенной
расшифровке. Для смены общих ключей/VPN нужно приостановить оба обработчика.

## Включение

1. Подключить Business-бота в Telegram с правом `can_reply` и нужными чатами.
2. В редакторе выбрать владельцев по Telegram ID (или добавить ID вручную).
3. Выбрать оформление, эмодзи, фильтры. Проверить на примере без отправки в чат.
4. Включить переключатель и сохранить. По умолчанию модуль выключен.

Бот редактирует уже отправленное сообщение: исходник может быть виден до
правки. Telegram ограничивает `can_reply` личными чатами с входящими за 24 часа.
Нет обхода этих ограничений и нет отправки нового сообщения вместо оригинала.

Новые исходящие сообщения принимаются только от выбранного владельца,
не от ботов и не из пересылок; команды, аудио и подписи медиа пропускаются.
Короткие сообщения фильтруются по настраиваемому порогу. Повторное событие
не создаёт вторую задачу. Редактирования не запускают новый цикл.
Ручная правка/удаление отменяют ожидающую задачу; Telegram не предоставляет
атомарной проверки версии сообщения, поэтому правку, уже принятую Telegram,
отменить таким способом нельзя. Изменение настроек отменяет очередь.

Ссылки, числа и Telegram entities защищаются маркерами перед запросом модели
и восстанавливаются с UTF-16 offsets. Потеря/дублирование маркера, незавершённый
ответ или превышение 4096 символов отменяют изменение. Проверка маркеров не
гарантирует полное семантическое тождество — стиль можно проверить на примере.

Исходный текст очереди зашифрован AES-256-GCM тем же ключом хранения,
но в отдельном `editor.json`. После обработки текст удаляется. В журнале
за сутки — только ID, даты, статусы и ошибки. Очередь ограничена 100 заданиями,
устаревает за 5 минут; входящие события старше 2 минут не принимаются.
После перезапуска незавершённые задания отменяются; неопределённый результат
Telegram не повторяется автоматически. OpenAI Responses используется с `store:false`.

## Проверки

`npm test` в корне включает `test/editor.test.js`.
`node --test tools/voice/test` проверяет прежние голосовые сценарии.
`PLAYWRIGHT_MODULE=/path/to/playwright node scripts/audit-editor.cjs`
проверяет панель локально в Chromium/WebKit, без настоящих Telegram/API ключей.
`AUDIT_OUTPUT` задаёт каталог скриншотов.

API панели: `/api/admin/editor`, POST `/configure`, POST `/preview`.
Доступ только управляющим Workspace; внутренний API `/api/editor` защищён
тем же service token, что и транспорт Business. При публикации обновить
контейнер `tools/voice` и основной `support-chat`.

Источники: https://core.telegram.org/bots/api#editmessagetext,
https://core.telegram.org/bots/api#businessbotrights,
https://developers.openai.com/api/reference/cli/resources/responses/methods/create.
