# Видео Telegram

Независимый сервис загрузки публичных видео YouTube (включая Shorts) и Instagram.
Управление: Workspace → Видео. Авторизация общая с Workspace и Mini App.

## Подключение

1. Создайте отдельного бота в BotFather. В BotFather Mini App включите **Guest Mode**.
2. В разделе «Видео → Подключение» сохраните токен и проверьте бота.
3. Включите бота. По умолчанию доступ открыт всем; ограничения меняются во вкладке «Настройки».
4. В поддерживающем Guest Mode клиенте Telegram напишите `@имя_бота ссылка` или ответьте на сообщение со ссылкой, указав `@имя_бота`. Добавлять бота в чат не требуется. В личном чате с ботом достаточно ссылки.

Guest Mode разрешает один ответ на вызов: отправляется готовое видео или причина ошибки, без предварительного сообщения. Бот не получает историю чата. Обычный бот в группе отвечает только на упоминание или ответ на своё сообщение. Для получения таких сообщений должны быть разрешены соответствующие обновления Telegram.

## Развёртывание

Скопируйте `.env.example` в `.env`. Сгенерируйте три независимых секрета: `openssl rand -hex 32`. `VIDEO_ENCRYPTION_KEY` должен содержать ровно 64 hex-символа. Значение `VIDEO_SERVICE_TOKEN` также добавьте в корневой `.env`; `VIDEO_SERVICE_URL=http://127.0.0.1:7800` задаёт адрес прокси Workspace.

В Caddy, **перед** общим reverse_proxy, добавьте:

```caddy
reverse_proxy /api/webhooks/telegram/video 127.0.0.1:7800
reverse_proxy /api/video/files/* 127.0.0.1:7800
```

`docker compose -f tools/video/compose.yml up -d --build`. Пересоберите Workspace после добавления настроек прокси. Порт 7800 должен быть свободен и исключён из выдачи FRP. Не публикуйте административный API напрямую.

## Ограничения

- Не более 20 ожидающих заданий, один загрузчик; по умолчанию 10 вызовов пользователя в час, 45 МБ, 180 секунд, 720p. Превышающие лимиты вызовы игнорируются.
- Файлы выдаются по случайной временной ссылке; срок по умолчанию 30 минут. Журнал — последние 30 заданий за сутки. После перезапуска незавершённая отправка не повторяется, чтобы не дублировать сообщения.
- Закрытые/платные публикации и требующие входа ссылки не поддерживаются. Источник может блокировать IP или требовать авторизацию. Успешный webhook сам по себе не подтверждает возможность скачать конкретное видео.
- Токен зашифрован в хранилище. Смена бота разрешена только при пустой очереди. Чужой webhook не перезаписывается автоматически.
- Для проверки отправки нужен настроенный отдельный бот; тесты используют подменённые API и не отправляют сообщения пользователям.

Документация: https://core.telegram.org/bots/features#guest-bots и https://github.com/yt-dlp/yt-dlp.
